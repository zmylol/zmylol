# Artwork notes

The profile's theme is inspired by **Frieren: Beyond Journey's End / 葬送的芙莉莲**. The forest, ivory, sage and antique-gold palette is a design interpretation.

## Header illustration

[Source illustration](frieren-journey.jpg) was generated with the built-in OpenAI image generation tool for this profile on 2026-09-15. ### Generation prompt

Create one premium panoramic hero illustration for the GitHub personal profile of zmylol, inspired by Frieren: Beyond Journey's End (葬送的芙莉莲). Depict the recognizable adult elf mage Frieren at the right third, long silver-white twin-tail hair, pointed elf ears, green eyes, a calm thoughtful expression, her familiar white cape with understated gold trim over dark clothing, a glimpse of her red-gem mage staff. Fully clothed. Framed as a waist-up/three-quarter figure, gazing slightly left across the landscape. A quiet northern forest path at late afternoon, old stone arch half reclaimed by moss, tiny pale-blue flowers and a few softly floating golden motes. Hand-painted fantasy anime illustration, delicate controlled linework, watercolor/gouache-like background texture, contemplative rather than action-focused, elegant and atmospheric. Wide cinematic panorama, approximately 3:1, intended for a 1200 by 420 GitHub banner. Leave the left half as low-detail deep pine-green forest shadows with generous negative space for a later title, transitioning to the brighter ivory figure on the right. Palette: deep forest green #173D35, sage #9EBAA6, warm ivory #F3ECD8, muted antique gold #CBB482, silver hair and subtle lavender-blue flower accents. No letters, typography, logos, signature, watermark, UI, panels or borders. Newly generated fan-theme artwork, not a reproduction of an existing manga panel.
