## One journey, two crops

[Full panorama](bridge-panorama.png) was generated with the built-in OpenAI image generation tool on 2026-09-15. It is original fan-theme artwork inspired by the characters and their journey, not a recreation of a specific chapter or an official illustration.

Himmel checks a map, Frieren studies a little spell beside blue flowers, and Heiter and Eisen wait at the bridgehead near a direction sign. The bridge connects them to a village beyond. These shared travel activities give the four companions a reason to be in the same place. The smaller profile title sits in the upper canopy so the right side can show the companions and their destination.

- [Himmel avatar](himmel-bridge-avatar.jpg): source rectangle `(156, 60)` to `(641, 545)`, 485 x 485 pixels.
- [Frieren banner illustration](frieren-journey.jpg): source rectangle `(721, 146)` to `(2107, 631)`, 1386 x 485 pixels.
- [Crop coordinates and measured layout](bridge-crop-map.json).
- [Generation prompt](bridge-generation-prompts.md).

Both images were cropped directly from the same 2146 x 732 master, then JPEG-encoded for the web. The crop boxes account for the gap and vertical offset measured on the desktop profile. GitHub rearranges the profile on smaller screens, so exact spatial alignment is specific to that desktop layout.

The rounded SVG embeds the banner JPEG, adds a small title and slow floating lights, and respects reduced-motion preferences. Publishing this repository alone does not change the account avatar; use the supplied matching avatar in GitHub profile settings.
